        What has been harmonised

        Each entry is one script that turns raw variables into a single harmonised column. Open one to read the code that produces it, the deposited files it draws on, and the raw variables it needs.

        Drag the ones you want into the bundle at the foot of the page — or use the ＋ beside each — and download them as R you can run on your own copy of the data: the runner, its libraries and one script per variable, with a README.

        Raw variables go in the same bundle. Search the metadata view and drag those in too — they come out as columns beside the harmonised ones.

        Status matters: draft means it has only been checked against fabricated data.
